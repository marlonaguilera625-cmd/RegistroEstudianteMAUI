El proyecto se identifica como RegistroEstudianteMAUI y corresponde a una aplicación multiplataforma desarrollada con .NET MAUI. Para esta actividad se trabajó sobre la interfaz de registro y su lógica de validación. La pantalla principal del formulario presenta un encabezado, una descripción breve y una sección para los datos personales, seguida de otra para la información académica. También incluye opciones de género, aceptación de términos y los botones Guardar y Limpiar. La aplicación está orientada a demostrar el uso de controles gráficos, la organización mediante layouts y la validación de entradas en una aplicación de escritorio o móvil.
